# lambda-rogue

**English** | [日本語](README.ja.md)

A terminal roguelike that reimplements the gameplay of Rogue 5.4.4 as a
clean-room project in Idris 2 with the rc2 backend. The game's truth lives in
a pure Core; presentation, input and effects are modernised with
[termui](https://github.com/stefan-hoeck/idris2-termui).

- The classic 26 levels, the Amulet of Yendor and the climb back, and permadeath.
- Monster, item and probability tables based on Rogue 5.4.4's public data.
- Deterministic RNG and replays. The same seed and command sequence produce
  the same result.
- An 80x24 classic layout and a 120x40 (or larger) wide layout.
- Mouse support, a command palette, themes, help, scores, and save/autosave.
- English and Japanese message catalogues, switchable with `--lang`,
  `settings.json`, or the `Ctrl-P` palette. Columns stay aligned by terminal
  cell width even when Japanese double-width glyphs are present.
- Scores record the cause of death and show it on the score screen.
- Automatic fallback to ANSI themes on terminals without TrueColor, and to a
  monochrome theme when `NO_COLOR` is set.
- Animation speed settings and automatic disabling through `NO_MOTION` or
  `--no-animation`.
- Every feature is reachable from the keyboard alone.

> This project does not copy Rogue 5.4.4's source code. It is reimplemented
> from public specifications, data tables and observed behaviour. See
> [`doc/rogue-reference.md`](doc/rogue-reference.md) for details.

## Requirements

- Idris 2 0.8.x with the rc2 backend (`idris2-rc2`)
- `rc2base` 0.1.0 and `termui` 0.1.0 installed for Idris 2
- A C compiler (gcc or clang)
- `script(1)` if you want to run the PTY smoke test

If `idris2-rc2` is not on `PATH`, point at it explicitly:

```sh
export IDRIS2="$HOME/.idris2/bin/idris2-rc2"
```

## Build and run

```sh
# Build the application
idris2-rc2 --codegen rc2 --build lambda-rogue.ipkg
./build/exec/lambda-rogue
```

With Clang 19, suppress the warning about comparison expressions generated by
the rc2 backend (`verify.sh` sets this automatically):

```sh
export IDRIS2_CFLAGS="-Wno-parentheses-equality"
```

## Verification

```sh
./verify.sh
```

This runs a clean build, the full test suite (1013 checks), and a PTY smoke test
that starts, draws and quits the executable. Test data is isolated under
`build/verify-data`; real saves, scores and settings are not touched.

## Startup options

```sh
./build/exec/lambda-rogue --seed 0123456789abcdef --lang ja --theme amber
```

- `--seed <16 lowercase hex digits>`: start a new run with the given seed.
  Any existing `save.json` / `autosave.json` is deleted.
- `--lang en|ja`: display language for this launch. It overrides
  `language` in `settings.json`; otherwise the saved value, or English when
  there is none, is used. While running, the `Ctrl-P` entry
  `Switch language` / `言語を切り替え` toggles the language and saves the
  choice to `settings.json`.
- `--theme <id>`: theme for this launch. It overrides `theme` in
  `settings.json`. The ids are `classic-cga`, `modern-dark`, `amber`,
  `green-phosphor`, `high-contrast`, `colorblind-safe`, and `monochrome`.
- `--no-color`: disable colour and start with the monochrome theme. The
  `NO_COLOR` environment variable does the same.
- `--no-animation`: disable animations. The `NO_MOTION` environment variable
  does the same. This disables them for this launch even when settings enable
  them.
- With no seed, a new one is generated from the launch time (UTC nanoseconds)
  and the PID. If a previous save exists, that run resumes instead.
- The seed is shown and copied on the share screen (`Ctrl-S`).
- Language, theme and animation are presentation-only: they never change game
  state, the RNG, replays or `gameDigest`.

Example `settings.json`:

```json
{
  "schema": "lambda-rogue.settings.v1",
  "theme": "classic-cga",
  "animation": true,
  "animationSpeed": "normal",
  "language": "ja",
  "keys": {}
}
```

## Main keys

| Key | Action |
| --- | --- |
| `h` `j` `k` `l` / arrows | Move west, south, north, east (attack a monster) |
| `y` `u` `b` `n` | Move diagonally |
| `.` / `5` | Wait one turn |
| `s` | Search the surroundings for traps and secret doors |
| `,` | Pick up an item underfoot |
| `>` / `<` | Descend / ascend stairs |
| `i` | Inventory |
| `q` / `r` / `e` | Quaff a potion / read a scroll / eat food |
| `w` / `W` | Wield a weapon / wear armour |
| `P` / `R` / `T` | Put on / take off a ring |
| `d` / `t` / `z` | Drop / throw / zap |
| `?` / `F1` | Help |
| `Ctrl-P` | Command palette |
| `F2` / `F3` / `F4` | Log filter / theme / animation |
| `F5` | Replay browser |
| `S` / `Ctrl-S` | Scores / share seed |
| `Q` / `Ctrl-C` | Quit |

- Moving into a monster attacks it.
- In the inventory, select a row and press Enter; clicks and double-clicks also
  work.
- Open the replay browser with `F5` or the palette, choose a file with the
  arrow keys, and press Enter to play it.
- During playback, Space pauses, `.`/Enter steps one command, `+`/`-` changes
  speed, `Left`/`Right` seeks by 10 commands, `Home`/`End` jumps to the start
  or end, `R` restarts, and Esc/q closes.
- Key bindings can be changed in `settings.json`; a settings screen is not yet
  implemented.
- Esc does not quit during normal play. Use `Q` or `Ctrl-C`.

## Saves and data

Data lives in `$XDG_DATA_HOME/lambda-rogue`, or
`$HOME/.local/share/lambda-rogue` when that is unset.

| File | Contents |
| --- | --- |
| `save.json` | Manual save written by the palette's "Save and quit" |
| `autosave.json` | Autosave every 10 forward turns |
| `scores.jsonl` | Completed runs, including the cause of death |
| `replays/*.json` | Replays of completed runs (seed + commands) |
| `settings.json` | Theme, animation, language, key bindings |
| `session.lock` | Session lock that prevents a second instance |

- On startup, `save.json` is resumed first, then `autosave.json`; the file
  that was read is deleted.
- On death or victory, the save is deleted and the score and replay are
  written.
- Loading a save cannot be used to avoid death.

## Accessibility

- The `monochrome` theme uses no colour and distinguishes information with
  bold, underline and inverse attributes only.
- `NO_COLOR` / `--no-color` disables colour completely.
- `NO_MOTION` / `--no-animation` disables animations.
- The high-contrast and colourblind-safe themes also use non-colour cues
  (underlines and symbols).
- Game glyphs are ASCII only, and every feature is reachable by keyboard.

## Fidelity and known differences

Differences from Rogue 5.4.4 are collected in chapter 17 of
[`doc/rogue-reference.md`](doc/rogue-reference.md). The main ones are:

- Weapon accuracy and damage bonuses are represented by a single `enchant`.
- Monsters appear with equal probability within a depth band rather than by
  the original table lookup.
- Monster groups, the monster possession table, ranged bow/throwing attacks,
  Xeroc's object mimicry, and dragon fire reflection are not implemented.
- Secret doors are generated from a fraction of closed doors; searching
  reveals them as closed doors. The original's exact generation probability
  is unconfirmed.
- Some potion durations, scroll targets and secondary wand effects are
  simplified.
- Fainting from hunger, death at `-850`, and levitation's trap immunity are not
  implemented.

M5 slice 1 aligned search, the searching ring, the healing / extra healing
dice and maximum-HP increase, and magic missile's 1d4 with 5.4.4. M5 slice 2
moved the game log, help, palette, status, prompts, scores and error messages
onto the English/Japanese catalogue; messages from old saves fall back to
their stored English text. It also added the palette language switch,
cell-width-aligned columns for double-width text, and the score cause column.
M5 slice 3 added theme auto-fallback and `--theme`, animation speed and reduced
motion, the replay browser with seeking, and accessibility improvements.
M5 slice 4 added secret doors: a fraction of closed doors now look like walls
until `Search` reveals them as closed doors, and the searching ring can find
them during its free search. M5 slice 5 gave Orcs their greedy behaviour:
they prefer visible gold, pick it up, and drop it when killed. M5 slice 6
limited the wand of light to the current room instead of the whole level.
