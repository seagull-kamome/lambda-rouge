# Rogue 5.4.4 リファレンス

- Status: Draft 1.1（M4 忠実性監査の確定版、BSD 3-Clause License）
- Date: 2026-11-07
- Target: Rogue 5.4.4 (Berkeley Rogue)
- 目的: lambda-rogue の忠実性の基準を、再現可能な公開データと実装の対応で固定する。
- 関連: `doc/design.md`, `doc/core-api.md`, `doc/m1-measurements.md`

## 1. 方針と確度

- 実装は原本のソースコードをコピーしない。公開されている 5.4.4 のデータ表、
  ヘッダに記載された定数、公開ガイド（Rogue Vade-Mecum 系の記述）、および
  実機で観測可能な挙動を照合し、クリーンルームで再実装する。
- 本ドキュメントの数値は、lambda-rogue の `Core` が実際に使う値である。
  「原本で確認した値」と「lambda-rogue の簡略化」を区別して書く。
- 確度の表記:
  - **確定**: 公開データ表・ヘッダ定数・複数の公開資料で一致し、実装に反映済み。
  - **導出**: 確定値から計算で求まる値（例: HP = レベル d8、経験値ボーナス）。
  - **簡略**: 原本の効果を lambda-rogue 向けに単純化したもの。差分を明記する。
  - **未確認**: 公開データがなく、lambda-rogue の暫定値。根拠を明記する。
- lambda-rogue の決定論は「同じ seed + 同じコマンド列」で再現できることを指す。
  原本の乱数列とのビット互換は非目標（設計判断 D8）。

## 4. モンスター

### 4.1 一覧

HP は `レベル d8`（**導出**）。攻撃は `個数 d 面` の並び。
経験値は基礎値（**確定**）。実際の獲得値は 4.3 の HP ボーナスを加える。
出現深度は両端を含む（**確定**、公開 5.4.4 シートの `上` / `下`）。

- 記号は `A`–`Z` の 26 種。`I` は invisible stalker ではなく **ice monster**、
  `J` は jackal ではなく **jabberwock**、`K` は kobold ではなく **kestrel**、
  `P` は purple worm ではなく **phantom**、`U` は ur-vile ではなく

- AC は低いほど良い。負の AC も有効。
- 攻撃が `0d0` の種類は、命中してもダメージは 0 だが特殊能力は発動する。
- HP は生成時に `レベル d8` で振る。レベルアップやポリモーフでも同じ式を使う。

### 4.2 出現

- lambda-rogue は深度帯に入る種類をすべて等確率で選ぶ。
  深度が上がるほど強敵の帯が増えるため、結果として危険度が上がる。
- 原本は `level + rnd(10) - 6` で表の添字を選び、範囲外を補正する。
  この選択式は公開シートの深度帯と一致しないため、lambda-rogue では採用しない
  （差分 17.2）。どちらも「深いほど強い」傾向は同じ。
- 起動時の各モンスターの睡眠確率は 80%。`UsuallyAsleep`（ice monster、
  leprechaun、nymph）は 92%。
- 眠っているモンスターは、プレイヤーが視界半径内かつ可視の位置にいると
  目を覚ます。ステルスの指輪は視界半径を半分にする。
- モンスターの行動順は ID 昇順。`Fast` または加速状態のモンスターは
  1 ターンに 2 回行動する。ただし 2 回目でプレイヤーが死亡した場合は行わない。

### 4.3 経験値

```
獲得経験値 = 基礎経験値 + (最大HP / 除数) * 倍率
除数 = レベル 1 なら 8、それ以外は 6
倍率 = レベル 10 以上なら 20、レベル 7–9 なら 4、それ以外は 1
```

- 端数は切り捨て。最大 HP は生成時の値を使う。
- 経験値は累積。レベルアップ時に経験値を消費しない。
- レベルアップに必要な累積経験値は
  `10, 20, 40, 80, 160, 320, 640, 1300, 2600, 5200, 13000, 26000,
  50000, 100000, 200000, 400000, 800000, 2000000, 4000000, 8000000`。
- レベルアップごとに最大 HP と現在 HP が `1d10` 増える。筋力は増えない。
- レベル 21 以上には上がらない。

### 4.4 特殊能力の実装

| 能力 | 対象 | lambda-rogue の挙動 |
| --- | --- | --- |
| 装備錆 (RustArmor) | aquator、rust トラップ | 防具の強化値を 1 下げる。`protected` または maintain armor の指輪で無効 |
| 凍結 (Freeze) | ice monster | 命中時に Held 3（実効 2 行動をブロック） |
| 火炎放射 (FireBreath) | dragon | 距離 2–6、同一直線・斜め 45 度、視認可能なら 1/5 で 6d6。必中 |
| 最大 HP ドレイン (DrainLife) | vampire | 命中時に最大 HP を 1d5 減らし、現在 HP も上限に切り詰める |
| 筋力ドレイン (DrainStrength) | rattlesnake | 命中時に筋力を 1 減らす。sustain strength で無効 |
| 経験値ドレイン (DrainExperience) | wraith | レベルを 1 下げ、経験値をそのレベルの下限にし、最大 HP も 1 減らす |
| 金窃取 (StealGold) | leprechaun | 所持金を奪ってテレポートする |
| アイテム窃取 (StealItem) | nymph | 所持品を 1 個奪ってテレポートする |

- venus flytrap の追加ダメージ（原本の `%%%x0` 書き換え）は未実装（差分 17.2）。
- ドラゴンの火炎は、火の杖を反射する処理までは実装していない（差分 17.2）。

## 5. 戦闘

### 5.1 命中

```
プレイヤーの命中率 (%) = 5 + 5 * プレイヤーレベル + 5 * モンスター AC
                         + 指輪の命中補正
モンスターの命中率 (%) = 20 + 5 * モンスターレベル + 5 * プレイヤー AC
```

- 1d100 を振り、出目が命中率以下なら命中。命中率は 0–100 に丸める。
- プレイヤーの AC は「10 - 防具の AC 改善 - 保護の指輪」で、低いほど良い。
  初期 AC は 10。防具は `防具の AC 値 - 強化値` を選手 AC とする。
- 筋力は命中率に影響しない（Rogue Vade-Mecum の式に筋力項はない）。
  筋力はダメージにのみ影響する。
- 複数攻撃のモンスターは攻撃ごとに 1d100 を振る。1 回でも命中すれば
  `Hit` 扱いになり、特殊能力は命中時に発動する。
- 攻撃が `0d0` でも命中判定に成功すれば特殊能力は発動する。

### 5.2 ダメージ

```
プレイヤーのダメージ = max 1 (武器ダイス + 筋力補正 + 武器強化値 + 指輪のダメージ補正)
モンスターのダメージ = 攻撃ごとのダイス（合計）
```

筋力補正（5.4.4 の筋力表）:

| 筋力 | 補正 |
| --- | --- |
| 6 以下 | 筋力 - 7 |
| 7–15 | 0 |
| 16–17 | +1 |
| 18 | +2 |
| 19–20 | +3 |
| 21 | +4 |
| 22–30 | +5 |
| 31 以上 | +6 |

- 初期筋力は 16。筋力の最大は 31。
- 武器を装備していない場合の素手は `1d4`。
- 武器を投げた場合は、装備時のダイスではなく投擲用ダイスを使う。

### 5.3 レベルアップ

- 経験値は累積し、消費しない。
- 1 レベルごとに最大 HP と現在 HP が `1d10` 増える。
- 筋力は増えない。
- 複数レベル分の経験値を一度に得た場合は、条件を満たす限り繰り返す。
- レベル 21 で打ち止め。

## 6. アイテム共通

### 6.1 種別の出現重み

`randomItemKind` は 0–99 の一様乱数で種別を選ぶ（**確定**）。

| 種別 | 重み | 累積しきい値 |
| --- | --- | --- |
| ポーション | 26 | 0–25 |
| 巻物 | 36 | 26–61 |
| 食料 | 16 | 62–77 |
| 武器 | 7 | 78–84 |
| 防具 | 7 | 85–91 |
| 指輪 | 4 | 92–95 |
| 杖 | 4 | 96–99 |

- 金はこの 100 点分布に含めず、通常アイテムの後に別枠で配置する。
- 食料は現状 `food ration` のみ。`slime mold` は未実装。
- アミュレットは 26 階に固定配置し、通常の抽選には含めない。

### 6.2 強化値と呪い

装備品（武器・防具）の生成時（**確定**）:

| 種別 | 呪い | 祝福 | 通常 |
| --- | --- | --- | --- |
| 武器 | 10% | 5% | 85% |
| 防具 | 20% | 8% | 72% |

- 呪いなら `-(rnd(3) + 1)`、祝福なら `+(rnd(3) + 1)`、通常は `+0`。
- したがって強化値の範囲は -3 から +3。
- 1d100 は常に 1 回消費する。強化値の大きさを振るのは呪い・祝福のときだけ。
- 呪われた装備は外せない。`remove curse` の巻物で呪いを解除できる。

指輪の生成時（**確定**）:

| 指輪 | 強化値 | 呪い |
| --- | --- | --- |
| protection | `rnd(3)`、0 は -1 | 0 のとき呪い |
| add strength | 同上 | 同上 |
| dexterity（原本の increase hit） | 同上 | 同上 |
| increase damage | 同上 | 同上 |
| aggravate monster | +0 | 常に呪い |
| teleportation | +0 | 常に呪い |
| その他 | +0 | なし |

- `rnd(3)` は 0–2 を返すので、強化値は -1 / +1 / +2 のいずれか。
- 上記以外の指輪は乱数を消費しない。

### 6.3 杖の充填数

| 杖 | 充填数 | 根拠 |
| --- | --- | --- |
| 光の杖 | 10–19 | `fix_stick` の `rnd(10) + 10` |
| それ以外 | 3–7 | `fix_stick` の `rnd(5) + 3` |

- 充填数はアイテム個体に保存する。識別済みの杖だけ UI に残数を表示する。
- 0 充填で振ると「The wand sputters.」となり、ターンは消費しない。
- 振ると 1 充填を消費し、杖の種別を識別する。

### 6.4 価値

`itemGoldValue` は 5.4.4 の価値表をそのまま使う。Gold は 1、Amulet は 0。
価値は現状スコア計算にのみ使う（未実装の項目は設計書 17 章）。

## 16. 乱数とターン進行

### 16.1 乱数

- `Core/Rng` は 128-bit の xoroshiro128++ を純粋な状態として実装する。
- `uniform bound` は `0 .. bound-1` の一様分布。2 の冪はマスク、
  それ以外は棄却サンプリングで偏りをなくす。
- `roll n sides` は `n` 個の `1..sides` の和。
- `chance percent` は 1d100 が `percent` 以下なら真。
- 同じ seed と同じコマンド列は同じ状態遷移を生む。リプレイはこの性質を使う。
- 生成・戦闘・モンスター AI・アイテム・罠の乱数消費順は実装で固定している。
  RNG の消費順を変えるとリプレイ互換性が壊れるため、変更時は注意する。

### 16.2 ターンの順序

1. プレイヤーのコマンドを解決する。コマンドがターンを消費しない場合はここで終了。
2. ターン番号を 1 進める。
3. 加速状態でない、または奇数ターンならモンスターが行動する。
   モンスターは ID 昇順。`Fast` / Hasted は 2 回行動。
4. モンスターが死亡・勝利していなければ、状態異常の経過、毒ダメージ、
   自然回復、空腹、再生の指輪、テレポートの指輪を処理する。
5. 視界と記憶マップを更新する。

- 階を移動したターンは、新しい階のモンスターを行動させない。
- プレイヤーが死亡したら、その時点で以降の処理を打ち切る。
- 空腹・毒・飢餓で HP が 0 になった場合も死亡する。

## 17. 既知の相違と簡略化

以下は「原本 5.4.4 と lambda-rogue が意図的に異なる」箇所である。
M4 では修正せず、ドキュメントに残して将来の課題とする。

### 17.1 データ・生成

1. **武器の強化値** — 原本は命中 `o_hplus` とダメージ `o_dplus` を別々に持つ。
   lambda-rogue は単一の `enchant` で両方を表す。`enchant weapon` の巻物も
   単一値を +1 する。そのため「命中だけ +1」のような状態は作れない。
2. **出現選択** — 原本は `level + rnd(10) - 6` でモンスター表を引く。
   lambda-rogue は公開シートの深度帯から等確率で選ぶ。
3. **群れ** — 5.4.4 の群れ生成（同じ種類の集団）は未実装。1 体ずつ生成する。
4. **モンスターの所持品** — `CarriedBy` と死亡時ドロップは実装済みだが、
   原本の `m_carry` 確率表（種類ごとの所持率）は未実装。
5. **部屋・トラップ密度** — 部屋サイズ、モンスター数、アイテム数、金塊数、
   トラップ数は公開データがないため M4 の暫定密度である。
6. **slime mold** — 食料は `food ration` のみ。`slime mold` は未実装。
7. **未識別名** — ポーションの色、巻物の題名、杖・指輪の外見はランごとに
   シャッフルする。原本の外見リストと完全一致するかは未確認。

### 17.2 効果・挙動

1. **ドラゴンの火炎反射** — 火の杖による反射は未実装。
2. **venus flytrap の追加ダメージ** — 原本の `%%%x0` 書き換えは未実装。
3. **orc の強欲** — `Greedy` フラグのみ。金を優先する AI は未実装。
4. **xeroc の擬態** — `MimicObject` フラグのみ。物体に見える表示は未実装。
5. **searching の指輪** — 搜索コマンド自体が未実装のため効果なし。
6. **adornment の指輪** — 原本どおりゲーム効果なし。
7. **巻物の sleep / scare / hold** — 対象と効果が原本と異なる（11 章）。
8. **remove curse** — 所持品すべてが対象（原本は装備中の防具のみ）。
9. **enchant weapon** — 命中・ダメージ分離なし（17.1-1）。
10. **ポーションの回復** — 最大 HP を増やさない。効果時間は短い固定式。
11. **ポーションの幻覚・盲目・透明** — 原本の `spread(850)` ではなく短時間。
12. **杖の light** — 階全体を照らす（原本は部屋のみ）。
13. **杖の magic missile** — 2d6（原本は 1d4）。
14. **杖の drain life** — 単体 2d6 + 自己回復（原本は HP 半減 + 周囲吸収）。
15. **杖の cancellation** — 状態異常解除のみ（原本は特殊能力も消す）。
16. **arrow / dart トラップ** — 命中判定・セーヴ・矢の落下なし。
17. **mysterious トラップ** — 固定メッセージ 1 種。
18. **浮遊** — トラップ無効・水・溶岩などの処理なし。
19. **飢餓** — 失神・`-850` 死亡なし。0 以下で毎ターン 1 HP。
20. **自然回復** — 静穏ターンではなくターン番号の剰余で近似。
21. **食料優先生成** — 原本の `no_food > 3` 処理なし。
22. **トラップ数** — 0–3（原本は `MAXTRAPS 10` 上限）。
23. **モンスターの遠距離攻撃** — 現状はドラゴンの火炎のみ。
    原本の弓矢・投擲武器を持つモンスターは未実装。
24. **モンスターの逃走・群れ・ドア開け** — 基本動作のみ。
25. **スコア** — アイテム価値と所持金は保持するが、死因別スコア計算は未実装。
